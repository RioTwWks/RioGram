## 7. Дорожная карта развития (после MVP)

MVP — прочный фундамент. Ниже — направления, как превратить RioGram в по-настоящему уникальный продукт.  
**Приоритет (совет):** начать с **«Призрачного режима»** и **«Анти-отзыва»**, затем встроенный переводчик и углублённая кастомизация UI.

### 7.1. Продвинутые техники обхода блокировок (стелс)

- [ ] Маскировка под легитимные российские сервисы (Yandex, VK, Gosuslugi) вместо только случайного выбора браузерного профиля
- [ ] Probe Resistance — корректная реакция прокси на «проверочные» запросы DPI без раскрытия природы сервиса
- [ ] Исследовать интеграцию с [telemt](https://github.com/telemt) / teleproxy как бэкенд с улучшенным Fake-TLS
- [ ] Автосмена TLS-отпечатка (Chrome / Firefox / Yandex) по таймеру или при проблемах с соединением

### 7.2. Расширение пользовательских функций

#### Призрачный режим (Ghost Mode)
- [ ] Скрытие статуса «онлайн»
- [ ] Скрытие статуса «печатает…»
- [ ] Скрытие подтверждений о прочтении (галочки)
- [ ] Просмотр «исчезающих» медиа без уведомления отправителя

#### Анти-отзыв и медиа
- [ ] Анти-отзыв (Anti-Recall): видеть удалённые и отредактированные сообщения
- [ ] Встроенный видеоплеер с изменением скорости воспроизведения
- [ ] Предпросмотр фото/видео при наведении (как на macOS)
- [ ] Встроенный переводчик сообщений в чате
- [ ] Поддержка VoIP (голосовые и видеозвонки) — см. также §6
- [ ] Быстрое переключение между несколькими аккаунтами — см. также §6

### 7.3. Глубокая кастомизация интерфейса

- [ ] Расширенные темы: произвольный акцентный цвет, шрифты (например Google Sans), скругления углов
- [ ] Скрытие элементов UI (кнопка mute, панель навигации, иконки)
- [ ] Настраиваемые жесты (свайпы по чатам и сообщениям)

### 7.4. Безопасность и приватность

- [ ] Local Premium: локальная разблокировка отдельных «премиум»-возможностей (например лимиты загрузки)
- [ ] Блокировка рекламы в каналах и ботах
- [ ] Отключение телеметрии Telegram (или только с явного согласия пользователя)

### 7.5. Интеграции и фишки

- [ ] Поддержка Telegram Mini Apps
- [ ] Поддержка LaTeX в сообщениях (рендер формул)
- [ ] Интеграции с внешними сервисами (автопостинг в личный канал / бот)

### 7.6. Долгосрочные идеи

### 7.7. Синхронизация с upstream TDLib

Нужно следить за обновлениями [оригинального TDLib](https://github.com/tdlib/td) и переносить патчи `DPI_BYPASS` на новые версии.

- [ ] Настроить уведомления о новых релизах upstream TDLib (GitHub Releases / watch repo)
- [ ] Добавить CI job или scheduled workflow: проверка нового тега `tdlib/td` → issue или Telegram-бот / email
- [ ] Документировать процесс merge upstream → `td/` (чеклист: `TDLIB_PATCHES.md`, конфликты, регрессия DPI)
- [ ] Зафиксировать в репозитории текущую базовую версию upstream TDLib (commit / tag)

Варианты нотификации:
- GitHub Action `schedule` + `gh api repos/tdlib/td/releases/latest`
- Dependabot-style custom workflow → создание Issue «Доступен TDLib vX.Y.Z»
- Подписка на RSS/Atom релизов GitHub + внешний сервис (IFTTT, n8n)
