## 3. Прокси и автоматическое переключение

### 3.1. Интеграция прокси в TDLib
- [ ] Использовать встроенные методы TDLib:
  - `addProxy` — добавить прокси с типом `proxyTypeMtproto` (или `proxyTypeSocks5`).
  - `getProxies` — получить список.
  - `enableProxy` — включить конкретный.
  - `removeProxy` — удалить.
- [ ] Добавить PhantomProxy (основной) и StealthGate (резервный) при инициализации.

### 3.2. Проверка доступности прокси

- [ ] Реализовать fallback: если все прокси недоступны, выдать пользователю уведомление.
- [ ] Переключение должно происходить без перезапуска приложения.

### 3.4. UI для управления прокси

  - Добавлять/удалять прокси вручную.
  - Включать/выключать автоматическое переключение.
  - Тестировать прокси нажатием кнопки.

### 3.5. Индикация статуса прокси

## ❗ Замечания
- Все изменения в TDLib должны быть задокументированы (комментарии в коде), чтобы легко переносить в новые версии TDLib.
- API-ключи (`api_id`, `api_hash`) не должны быть захардкожены в клиенте — либо подгружаться с сервера, либо генерироваться динамически.
- При возникновении ошибок сборки TDLib обращаться к официальной документации.
- Регулярно делать коммиты и пушить в приватный репозиторий.
