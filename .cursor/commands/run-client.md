# Запуск

1. Убедиться, что прокси-серверы запущены (PhantomProxy и StealthGate).
2. В терминале из корня проекта:
   ```bash
   flutter run -d windows   # или macos, linux, android, ios
   ```
3. При первом запуске будут запрошены `api_id` и `api_hash` (ввести вручную или из переменных окружения).
